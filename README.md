# LOOP Membership

매장 태블릿에서 전화번호 기반 멤버십을 운영하고, 관리자가 고객·재방문·적립 정책을 관리하는 Next.js + Google Sheets 앱입니다.

## 주요 기능

- 관리자가 적립 방식을 선택: `방문 1P` / `도장 쿠폰` / `결제금액 % 적립`
- 적립 방식별 잔액과 원장을 서로 분리해 저장하고, 방식을 바꿨다가 돌아와도 기존 잔액 보존
- 결제금액 적립 방식에서 다른 방식으로 변경할 때 기존 결제 포인트가 있으면 확인 경고 필수
- 도장 쿠폰 시각화, 쿠폰 완성 혜택 및 직원 PIN 사용 확인
- 결제금액 × 설정 비율의 포인트를 계산하며 소수점은 버림
- 신규 고객 유입경로 설문 + 재방문 고객의 업종별 이유 설문
- 재방문 설문은 업종 프리셋을 제공하고 관리자가 최대 6개 문구·감사 메시지를 수정 가능
- 관리자 KPI 카드 클릭 시 날짜별 선 그래프 분석
- 고객별 방문 포인트 내역 확인 및 관리자 포인트 조정
- 관리자 목록에서는 전화번호를 마스킹해 전달
- 개인정보 삭제 요청 시 관련 방문·거래·각 적립 원장·재방문 이유 기록 함께 삭제
- 빠른 연속 탭 중복 요청 방지

## Google Sheets 구성

서비스 계정을 Google Sheet의 **편집자**로 공유하면 필요한 시트가 자동으로 생성됩니다.

### Customers

`id | phone | source | visits | points | lastVisit | privacyConsentAt | privacyConsentVersion | stamps | paymentPoints`

- `points`: 방문 1P 방식 잔액
- `stamps`: 도장 방식 잔액
- `paymentPoints`: 결제금액 방식 잔액

### 운영 기록

- `Visits` — `date | phone | source | points`
- `Transactions` — 기존 방문 포인트 적립·사용·관리자 조정 감사 기록
- `PointLedger` — 방문 포인트 전용 원장
- `StampLedger` — 도장 적립·사용 전용 원장
- `PaymentPointLedger` — 결제금액, 적립률, 증감, 잔액을 포함한 결제 포인트 전용 원장
- `ReturnReasons` — 재방문 이유 응답

### 설정

- `Settings` — 방문 포인트 사용 혜택
- `PaymentRewards` — 결제 포인트 사용 혜택
- `EarningSettings` — 현재 적립 방식, 결제 적립률, 도장 목표, 도장 혜택, 업종, 재방문 설문 문항

## 적립 방식 전환 원칙

세 잔액은 자동으로 변환하거나 합산하지 않습니다.

예를 들어 한 고객이 방문 포인트 `7P`, 도장 `4개`, 결제 포인트 `2,350P`를 보유한 상태에서 도장 방식으로 변경해도 나머지 잔액은 그대로 보존됩니다. 나중에 결제금액 적립 방식으로 돌아오면 `2,350P`에서 이어집니다.

결제금액 적립 방식에서 다른 방식으로 나갈 때 결제 포인트 잔액이 남아 있으면 서버에서도 확인 플래그를 요구해 실수로 전환하지 않도록 합니다.

## 고객 흐름

1. 전화번호 입력 및 가입 여부 확인
2. 신규·재동의 대상 고객만 개인정보 수집·이용 동의
3. 신규 고객은 최초 유입경로 선택
4. 재방문 고객은 업종별 재방문 이유 설문을 선택하거나 건너뜀
5. 현재 관리자 설정에 따라 방문 포인트 / 도장 / 결제금액 적립 진행
6. 혜택 사용 시 직원 관리자 PIN 확인
7. 완료 후 약 12초 뒤 다음 고객 화면으로 복귀

## 관리자 흐름

관리자는 4자리 PIN 인증 후 다음 기능을 사용할 수 있습니다.

- 전체 고객 / 누적 방문 / 재방문 / 현재 적립방식 잔액 KPI 확인
- KPI 클릭 후 30일 / 90일 / 전체 날짜별 선 그래프 확인
- 적립 방식 선택 및 세부 설정
- 업종별 재방문 설문 프리셋 선택 후 최대 6개 문항·감사 문구 수정
- 방문·결제 포인트 혜택 설정
- 고객 상세 확인, 방문 포인트 거래 이력 및 잔액 조정
- 고객 개인정보 및 관련 원장 삭제

분석 API는 관리자 PIN으로 보호하며 브라우저에는 날짜별 집계값만 전달하고 원본 전화번호를 반환하지 않습니다.

## 개인정보 운영 주의

현재 동의 화면은 수집·이용 목적, 수집 항목, 보유기간, 동의 거부 권리, 미성년자 안내, 삭제·철회 요청 경로를 구분해 표시합니다. 동의 문안 버전은 `2026-09-01-v1`로 기록합니다.

실제 매장 운영 전에는 사업자명, 개인정보 보호 책임자/연락처, 처리위탁·제3자 제공 여부, 파기 절차 등 해당 사업장의 전체 개인정보 처리방침을 별도로 확정하고 공개해야 합니다. 이 구현은 개별 법률 자문을 대체하지 않습니다.
